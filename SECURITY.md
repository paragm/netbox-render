# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

Only the latest release gets patches.

## Reporting

Use [GitHub Security Advisories](https://github.com/paragm/netbox-render/security/advisories/new). Don't open a public issue.

I'll fix confirmed vulnerabilities and credit the reporter unless they prefer to stay anonymous.
